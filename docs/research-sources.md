# Research sources

Primary sources used for the initial contract:

- Exa JavaScript SDK, `exa-js` 2.18.1, MIT:
  <https://github.com/exa-labs/exa-js>
- Exa API documentation: <https://docs.exa.ai>
- Context7 TypeScript SDK, `@upstash/context7-sdk` 0.3.1, MIT:
  <https://github.com/upstash/context7/tree/master/packages/sdk>
- Official Context7 Pi extension, `@upstash/context7-pi` 0.1.2, MIT:
  <https://github.com/upstash/context7/tree/master/packages/pi>
- Pi extension documentation:
  <https://github.com/earendil-works/pi/blob/main/packages/coding-agent/docs/extensions.md>

Design references reviewed but not copied include `pi-web-access`,
`@mrclrchtr/supi-web`, `@xaccefy/pi-lookup`, and `pi-all-search`, all under MIT
at the versions recorded during implementation research.

# Roadmap

## Phase 1 — interactive vertical slice

- provider-neutral contracts;
- direct Exa search and contents;
- direct Context7 library resolution and focused context;
- bounded cancellation-aware service;
- interactive `search` and `fetch` tools;
- process-local shared service provider;
- packed package and local live qualification.

## Phase 2 — delegated research

- generic host-brokered tool-provider contract in pi-subagent;
- exact pi-web capability and implementation identity in subagent preflight;
- host-only credentials;
- delegated `search` and `fetch` tools;
- parent receives only child synthesis and citations.

## Later

- Markdown-first direct HTTP extraction with SSRF protection;
- bounded resource artifacts and delegated VM projection;
- immutable public repository snapshots;
- optional private cache with explicit retention.

Browser execution, authenticated pages, arbitrary provider fallback, workflow
execution, and publication remain out of scope.
